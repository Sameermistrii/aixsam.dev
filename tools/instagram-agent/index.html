What is Instagram Agent Skill?

Instagram Agent Skill is a free, MIT-licensed set of 13 Claude skills by Jake Schincariol that help you run an Instagram account: write Reels from 26 hook formulas, find what's working in your niche, write captions, plan the week and score your profile.

It needs no Instagram login and no API key, and it never posts, comments or DMs for you. It writes drafts; you post. Every skill reads a short voice.md file about how you talk, so spend ten minutes filling it in first.

What Instagram Agent Skill can do

  • /ig-reel turns one idea into three scored hooks, a script, on-screen text and a timed beat sheet.
  • /ig-viral finds reels that beat their own account's usual numbers in your niche and names the formula.
  • /ig-caption writes the caption and shows exactly what fits before the "… more".
  • /ig-carousel and /ig-story swipe-post copy and files, and a daily story sequence.
  • /ig-profile scores your profile out of 100 on a 12-part rubric and rewrites what lost points.
  • /ig-plan the week: what to post, which format, when, and accounts to engage with.
  • /ig-human the humanizer: strips em dashes, AI vocabulary and hidden watermark characters, then checks the draft.

What you need

  • A paid Claude plan (Pro, Max, Team or Enterprise) with code execution turned on. Or Claude Code.
  • No Instagram login, no API key, no sign-up. The skills never post, comment or DM for you.
  • Optional: Python 3 (Claude Code only) for the hook scorer, beat timer, caption checker and humanizer scripts. Nothing to install with pip.

Setup, step by stepcopy each command with the button on the right

Claude Desktop appno coding

  1. Add the marketplace

    Open Claude Desktop → Customize (left sidebar) → Plugins tab → Add (top right) → Add marketplace → Add from a repository. Paste this and sync:

    Jakeschincariol/instagram-agent-skill

  2. Install the plugin

    Switch to the Discover tab, find instagram-agent and click the + on its card. Then switch to Yours to check it's listed and turned on.

    This is where most people get stuck: syncing only puts it in Discover. You still have to press + on the card.

claude.ai (web)

  1. Same steps in the browser

    On claude.ai: Customize → Plugins → Add → Add marketplace → Add from a repository → paste Jakeschincariol/instagram-agent-skill → sync. Then find instagram-agent under Discover and click Add.

Claude Codeterminal / VS Code / JetBrains

  1. Paste the link (the way from the reel)

    Paste this into Claude Code and it installs the skills for you:

    https://github.com/Jakeschincariol/instagram-agent-skill

Install this skill, then confirm /ig-reel works.

  2. Or install it as a plugin

    /plugin marketplace add Jakeschincariol/instagram-agent-skill
/plugin install instagram-agent@instagram-agent-skill

    Want it in one project only? Copy the skills/ig-* folders into that project's .claude/skills/ instead.

Everyone10 minutes, worth it

  1. Teach it your voice

    Every skill reads a file called voice.md. Easiest way: start a new chat, paste three of your own reel scripts or captions, and say:

    Write my voice.md from these.

    In Claude Code it lives at ~/.claude/instagram/voice.md. The blank template is in the repo under templates/voice.md.

  2. Start a new chat and ask

    Type a command like /ig-reel or just ask in plain words. Try one of the prompts below. You always get a draft first, and you post it yourself.

Try this first

/ig-reel [your idea, with a real number if you have one]
/ig-plan Plan my Instagram week. I post about [your niche] for [your audience].
/ig-profile Score my profile out of 100 and tell me what to fix: [paste your bio, link and highlights]
/ig-comment Write a comment for this post: [paste the caption]
/ig-reply Sort these replies and draft answers: [paste the comments under your post]
/ig-viral Find what's working in my niche: [your niche]

The 13 skills

  • /ig-reel one idea into a Reel: 3 hooks from 26 formulas, scored, then script, on-screen text and timing
  • /ig-viral finds posts that beat their account's usual views, names the hook formula, writes a swipe file
  • /ig-caption checks your caption and the ~125 characters people see before "more"
  • /ig-carousel cover, slide copy and 1080×1350 images
  • /ig-story a daily story sequence and DM funnel
  • /ig-profile scores your profile out of 100 and lists fixes in order
  • /ig-plan your week: what, when, which format, and 10 accounts to engage with
  • /ig-human strips the AI tells out of a draft
  • /ig-comment comments for other people's posts
  • /ig-reply replies to comments on your posts, most important first
  • /ig-dm keyword DMs, first messages, collab pitches and follow-ups
  • /ig-repurpose one video, podcast or newsletter into a week of posts
  • /ig-audit ranks your published posts by how far they beat your usual reach

Stuck?

The skills don't turn on

Check the plugin is under Yours and enabled, then start a brand-new conversation. In Claude Code, restart it after installing.

I pasted the link and Claude says it can't install it

Pasting the link works in Claude Code. In the Claude app, use the Plugins steps above instead.

Can it post to Instagram for me?

No. It writes drafts and you post them yourself. It never posts, comments, follows or DMs, and it never asks for your Instagram password.

Is /ig-viral safe for my account?

It reads public posts at human speed through your own browser. It doesn't log in as you or scrape in bulk. If Instagram won't show enough, it can study YouTube Shorts hooks instead.

No paid Claude plan?

Open any skill's SKILL.md on GitHub, copy it, and paste it at the top of a normal chat. That skill then runs as a mode. You lose the scoring scripts, but the writing still works.

Questions people ask

Does it need my Instagram password?

No. It never logs in to Instagram and never posts, comments or DMs. You copy the drafts and post them yourself.

Is it free?

Yes, MIT licensed. You need Claude with skills (a paid plan with code execution) or Claude Code.

What is voice.md?

A short file describing how you talk. Every skill reads it, which is why the drafts sound like you. You can ask Claude to write it from three of your reels.

Does it work without Claude Code?

Paste a single SKILL.md into a chat and it works as a mode, but you lose the Python tools that score hooks and run the humanizer.

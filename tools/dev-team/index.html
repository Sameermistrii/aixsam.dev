What is Claude Code Dev Team?

This guide sets up five free tools that turn Claude Code from a single coder into something closer to a small team: a planner that slows it down before it writes code, a researcher that pulls current library docs, a reviewer, a cleaner, and a leadership crew of specialist reviews.

Superpowers (by Jesse Vincent) makes Claude ask what you're really building, write a spec you approve in short chunks, then a plan of small tasks it builds test-first. Context7 (by Upstash) fetches up-to-date, version-specific documentation so Claude stops inventing APIs that don't exist. /code-review and /simplify are built into Claude Code. gstack, by Y Combinator's Garry Tan, adds 23 specialist roles, from a CEO-style plan review to a QA lead that tests in a real browser.

Add them one at a time and try each before adding the next, so you know what each one changes.

What Claude Code Dev Team can do

  • Plan first Superpowers turns a vague idea into a spec and a step-by-step plan before any code is written.
  • Build test-first Superpowers' plans follow red/green TDD, YAGNI and DRY, and can run for hours without drifting from the plan.
  • Current docs add use context7 to a prompt and Claude reads today's docs for your libraries.
  • Catch bugs /code-review checks a change before your users find the problems.
  • Clean up /simplify removes complexity Claude added along the way.
  • Specialist reviews gstack's /plan-ceo-review, /review, /qa, /cso and more.

What you need

  • Claude Code on a paid Claude plan.
  • Node.js (for Context7).
  • Git and Bun (for gstack).
  • Add one tool at a time and try it before adding the next.

Setup, step by stepcopy each command with the button on the right

01 · PlannerSuperpowers

  1. Install Superpowers

    Inside Claude Code:

    /plugin install superpowers@claude-plugins-official

    It makes Claude brainstorm with you, write a spec and a plan of small tasks, then build test-first. github.com/obra/superpowers

02 · ResearcherContext7

  1. Install Context7

    In your terminal:

    npx ctx7 setup --claude

    It signs you in and sets up Claude Code. Then add use context7 to a prompt and Claude pulls the latest docs for your libraries. Free tier; a free key from context7.com gives higher limits. github.com/upstash/context7

03 · Reviewerbuilt in

  1. Run a code review

    Nothing to install. After Claude changes code, type:

    /code-review

    It checks the change for bugs before your users find them.

04 · Cleanerbuilt in

  1. Simplify the code

    Commit your work first so you can undo, then type:

    /simplify

    It cleans up your recent changes (repeated logic, over-complicated functions) without changing what the code does.

05 · Leadershipgstack by Garry Tan

  1. Install gstack

    Paste into your terminal:

    git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack && cd ~/.claude/skills/gstack && ./setup

    23 specialists as slash commands, from /office-hours and /plan-ceo-review to /qa, /cso (security) and /ship. github.com/garrytan/gstack

All together

  1. Run the whole team for every feature

    Paste this into Claude Code:

    I want to build [describe the feature]. Work as my dev team, in this order, and wait for my approval after each step:
1. Leadership: run /plan-ceo-review to challenge the scope, then /plan-eng-review to lock the approach.
2. Planner: use Superpowers to brainstorm the details with me and write a plan of small tasks.
3. Researcher: use context7 for any library involved, with the docs for the exact versions in my project.
4. Build test-first, one task at a time.
5. Reviewer: run /code-review and fix the serious issues.
6. Cleaner: run /simplify, keeping behaviour exactly the same.
7. QA: run /qa to test the feature in a browser.

Heads up: gstack's setup runs a script on your computer, so only install it from github.com/garrytan/gstack. Its browser skills like /qa can drive a real browser: close email, banking and admin tabs first. Every add-on uses some of your Claude plan, so keep only the ones you use.

Stuck?

gstack setup fails

It needs Git and a recent Bun (older Bun versions are refused). On Windows it also needs Node.js.

Do I need all five?

No. /code-review and /simplify are already in Claude Code. Start there, then add the others one at a time.

Questions people ask

Are all five really free?

Yes. Superpowers and gstack are free and open source, /code-review and /simplify come with Claude Code, and Context7 has a free tier (a free key from context7.com raises the limits). You still need Claude Code itself on a Claude plan.

Do I need all five?

No. Start with Superpowers. Add Context7 if Claude keeps getting library code wrong, and gstack when you want deeper reviews and browser testing.

Does gstack work on Windows?

Yes, through Git Bash or WSL: run .\setup.ps1 in PowerShell from the gstack folder. If Windows 11's Smart App Control blocks its browser tool, the other gstack skills still work.

Will these slow Claude down or use more tokens?

Planning and reviews do add steps, and that's the point: they catch mistakes that would cost more to fix later. Install one at a time so you can feel the difference.

What is LinkedIn Skills?

LinkedIn Skills is a free, MIT-licensed bundle of 12 Claude skills by Serge Bulaev that write your LinkedIn posts, comments and replies in your own voice. They draft, strip the typical AI tells, and wait for your approval: nothing is published unless you say so.

You don't need to code. On claude.ai or Claude Desktop you add it as a plugin in a few clicks; it also works in Claude Code, the Codex CLI and other agents that read SKILL.md files. The right skill switches on by itself when you mention LinkedIn.

What LinkedIn Skills can do

  • Post Writer drafts posts from 20 hook formulas, picked by what you want the post to achieve.
  • Comment Drafter and Reply Handler draft a comment from any post URL, or sweep a whole thread and draft replies in one batch.
  • Post Audit and Humanizer check a draft against platform rules and AI patterns, and remove the phrases readers recognise as AI.
  • Hook Extractor turns any viral post into a blank template for your own topic.
  • Content Planner a 7-day plan with topics, formats, hooks and posting times.
  • Profile Optimizer rewrites your headline, About, Featured and Experience sections.
  • Interviewer, Repurposer, Engagement Monitor, Employee Advocacy build a story bank from your career, turn tweets or videos into LinkedIn posts, track replies, and plan a team posting program.

What you need

  • A paid Claude plan (Pro, Max, Team or Enterprise) with code execution turned on. Or Claude Code.

Claude Desktop appno coding

  1. Add the marketplace

    Open Claude Desktop → Customize (left sidebar) → Plugins tab → Add (top right) → Add marketplace → Add from a repository. Paste this and sync:

    sergebulaev/linkedin-skills

  2. Install the plugin

    Switch to the Discover tab, find the plugin and click the + on its card. Then switch to Yours to check it's listed and turned on.

    This is where most people get stuck: syncing only puts it in Discover. You still have to press + on the card.

claude.ai (web)

  1. Same steps in the browser

    On claude.ai: Customize → Plugins → Add → Add marketplace → Add from a repository → paste sergebulaev/linkedin-skills → sync. Then find it under Discover and click Add.

Claude Codeterminal / VS Code / JetBrains

Stuck?

The skills don't turn on

Check the plugin is under Yours and enabled, then start a brand-new conversation.

Can it post to LinkedIn for me?

Optional. Auto-posting uses Publora, a separate service with its own API key (and reading LinkedIn data uses Apify). Without them, the skills just write drafts you copy and post yourself.

Questions people ask

Is it free?

The skills are free and MIT licensed. You need a paid Claude plan (Pro, Max, Team or Enterprise) with code execution turned on, or Claude Code.

Will it post to LinkedIn by itself?

No. It only writes drafts. Auto-posting is an optional extra through a third-party service (Publora) that you'd have to connect yourself.

Will its posts pass AI detectors?

The authors are honest about this: the humanizer removes common AI tells but doesn't promise to beat detectors, because no edit reliably does. It even shows how much the detectors disagree with each other.

I synced the marketplace but can't find the skills

Syncing only adds the plugin to Discover. Press the + on the plugin card, then check it's listed under Yours.

Cloning on Windows loads no skills

The repo uses symlinks, which Windows only creates with Developer Mode or git config core.symlinks true. Use the plugin install instead, or the junction command in the README.

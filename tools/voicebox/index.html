Voicebox

A free AI voice studio on your own computer: clone a voice from a short sample, generate speech in 23 languages, and dictate into any app.

Reel keyword: REPOVoice AIFree · MITRuns locallyMac · Windows
Start setup ↓Official GitHub repo

What you need

  • A Mac (Apple Silicon or Intel) or a Windows PC. Linux has to build from source for now.
  • A 10–30 second clean recording of the voice you want to clone (or record it in the app).

Setup, step by stepcopy each command with the button on the right

  1. Download the app

    • Mac with Apple Silicon (M1–M4)
    • Mac with Intel
    • Windows

    Linux: follow voicebox.sh/linux-install.

  2. Create a voice

    Open Voicebox → Voices → + New Voice. Give it a name and language, then upload a 10–30s clip (WAV, MP3 or M4A) or press Record Sample. Click Create Profile.

    Clean audio with no background noise gives the best clone.

  3. Generate speech

    Go to Generate, pick your voice, type your text and press Generate. Then Play or Download.

    The first run is slower because it loads the model. After that it's quick.

  4. Extras worth trying

    • Stories: a timeline for podcasts and multi-voice scenes.
    • Dictation: hold a hotkey anywhere, speak, and the text is typed for you.
    • Tags like [laugh] and [sigh] work with the Chatterbox Turbo engine.

Try this first

Hello! This is my first voice generation with Voicebox.
Record a 20-second sample reading a news paragraph, then generate a whole script in that voice

Heads up: Only clone voices you have permission to use: your own, or someone who agreed.

Stuck?

Can I run it in Docker?

Yes: clone the repo and run docker compose up.

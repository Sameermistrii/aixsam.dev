What is MoneyPrinterTurbo?

MoneyPrinterTurbo is a free, open-source (MIT) app by harry0703 that turns one topic or keyword into a finished short video. It writes the script with an AI model, finds matching stock footage, adds a voiceover, syncs subtitles, adds background music and renders the video, while letting you change any step.

It runs on Windows, Mac or Linux without a graphics card, because it edits stock clips instead of generating video. You can use it through a web page in your browser, an API, a command line or an AI agent.

Despite the name, it doesn't make money by itself: it makes videos fast. What you do with them is up to you.

What MoneyPrinterTurbo can do

  • Topic to video script, voice, footage, subtitles and music in one go, or bring your own script.
  • Many AI models OpenAI, Claude, Gemini, DeepSeek, Qwen, Grok and more for the script, or Ollama for a free model on your own PC.
  • Free footage and voice stock clips from Pexels and Pixabay, and Edge TTS voices that need no key.
  • Your own material upload your own images and videos, or plug in AI video generators if you have a key.
  • Subtitles your way font, position, colour, size, outline and background.
  • Every format 9:16 (1080×1920), 16:9 (1920×1080) or 1:1 (1080×1080), and batches of several versions at once.

What you need

  • A Windows, Mac or Linux computer. 4 GB RAM works, 8 GB is better. No graphics card needed.
  • An AI key to write the script: OpenAI, Gemini, DeepSeek, Claude and many more. Or Ollama to run a free model on your own PC.
  • A free Pexels API key for the stock video clips.
  • Mac or Linux only: Python 3.11 (python.org).

Setup, step by stepcopy each command with the button on the right

Windowseasiest: one-click package

  1. Download the one-click package

    Open the latest release and, under Assets, download the .7z file. Not "Source code (zip)": that one has no start.bat.

    Extract it with 7-Zip into a simple folder like C:\MPT. Avoid folder names with spaces or non-English letters.

  2. Update, then start

    Double-click update.bat first (gets the latest code), then double-click start.bat. Your browser opens the app.

    Blank page? Open it in Chrome or Edge.

Mac & Linuxinstall with pip

  1. Make a clean Python environment

    Open Terminal in an empty folder and run:

    python3 -m venv .venv
source .venv/bin/activate

  2. Install and start

    python -m pip install mpt
mpt webui

    The app opens in your browser.

    The official package is mpt. The package called "MoneyPrinterTurbo" on PyPI is made by someone else, so don't install that one.

Everyonefirst video

  1. Add your keys

    In the app's basic settings:

    • Pick your AI provider and paste its key (or choose Ollama for a free local model).
    • Paste your Pexels key.
    • For the voice, pick Azure TTS V1: it runs on Edge TTS, which is free and needs no key.

  2. Make your first video

    Type a topic, choose 9:16 for Reels/Shorts, and hit generate. It writes the script, finds clips, adds the voiceover, subtitles and music, and renders an MP4.

    Finished videos are saved in the app's data folder under storage/tasks (Windows: %LOCALAPPDATA%\MoneyPrinterTurbo, Mac: ~/Library/Application Support/MoneyPrinterTurbo).

Stuck?

Download FFmpeg from gyan.dev, extract it, and put its path in config.toml:

[app]
ffmpeg_path = "C:\\Users\\you\\Downloads\\ffmpeg.exe"

Questions people ask

Is MoneyPrinterTurbo free?

The app is free and MIT licensed. Pexels footage and Edge TTS voices are free too. The AI that writes the script may cost a little, unless you use a free local model with Ollama.

Do I need a graphics card?

No. It edits stock footage, so an ordinary computer with 4 GB of RAM works (8 GB is better).

Which pip package is the real one?

mpt. A package named "MoneyPrinterTurbo" on PyPI is made by someone else, so don't install that one.

Can it make videos in Hindi?

It can write multilingual scripts, and Edge TTS has Hindi voices. Pick a Hindi voice in the voice settings and check the subtitle font shows Hindi correctly.

Can I post the videos as my own?

The footage comes from free stock libraries, so check each library's licence, and add your own angle. Plain stock-clip videos tend to perform worse than ones with a real point of view.

My reel pipeline

I don't film my reels and I don't open a video editor. Claude writes the script, an AI voice reads it, code works out when every word is spoken, a cartoon mascot moves its mouth with the voice, and the whole reel is a web page that a browser turns into a video, frame by frame. This page gives you a free starter kit with the same core and every command to run it. Honest note: I still check the script, the facts and the final video myself. The code does the editing, not the thinking.

How it works

1 · Script. I give Claude the trending reel and the tool's link. It reads the README, checks every number, writes the script. I approve it.
2 · Voice. An AI voice (I use ElevenLabs) reads the script. Code listens back to check no words were changed.
3 · Captions. "Forced alignment" lines the script up with the audio, so every word gets its exact start and end time.
4 · Mascot. Two pictures of the same character: mouth closed and mouth open. The loudness of the voice decides which one shows in each frame.
5 · Animation. The reel is one web page. Cards pop in on the exact word you say ("@code" = when "code" is spoken).
6 · Render. A browser takes a screenshot of every frame (30 a second) and ffmpeg glues them to the voice. Out comes reel.mp4.

What you need

  • A computer: Mac, Linux, or Windows. Everything runs on your own machine.
  • Python 3.9+ and ffmpeg (installed in step 0).
  • A voice: an AI voice (ElevenLabs, or any text-to-speech) or your own voice recorded on your phone. Both work.
  • Claude (the free plan is fine) or Claude Code, for the script. Optional: you can write it yourself.
  • Your own mascot: two PNG pictures, mouth closed and mouth open (step 4). The kit comes with a simple placeholder face so you can test first.
  • Cost: the kit and every tool here are free. ElevenLabs has a free plan with a monthly limit; check its terms before you earn money from the videos.

Step 0 · Installonce, about 5 minutes

  1. Download the kit

    reel-kit.zip has 6 files: build.py, reel.html, render.py, script.txt and two placeholder mascot pictures. Unzip it into a new folder and open a terminal in that folder.

  2. Install ffmpeg

    Mac (with Homebrew):

    brew install ffmpeg

    Linux / WSL:

    sudo apt install -y ffmpeg

    Windows (PowerShell):

    winget install Gyan.FFmpeg

    Check it worked: ffmpeg -version prints a version. On Windows, open a new terminal first.

  3. Install the Python parts

    pip install pocketsphinx numpy playwright
python3 -m playwright install chromium

    PocketSphinx does the word timing (its English model comes inside the package, nothing else to download). Playwright drives the browser that renders the frames. On Windows, type python instead of python3 everywhere on this page.

  4. Test the kit before changing anything

    The kit comes with a script but no voice. Record yourself reading script.txt on your phone (or make it with any AI voice), put the file in the folder, then:

    ffmpeg -i voice.mp3 -ac 1 -ar 44100 vo.wav
python3 build.py
python3 render.py

    You get reel.mp4: captions in sync, the face talks, and cards pop in on "shoot", "edit", "code" and "pipeline". If that works, everything is installed.

Step 1 · ScriptClaude writes, you approve

  1. Ask Claude for the script

    Paste this into Claude and fill in the brackets. The rules in it are the ones I use: a hook with a real before → after, short lines, and no made-up numbers.

    Write a 35–45 second Instagram reel script (about 100 words) about [tool / topic].
Sources: [GitHub link / official page]. Read them first.
Rules:
- First sentence = the hook: who, what they do, the result, and a TRUE before → after
  (example: "I replaced a ₹2,000/month app with a free GitHub repo").
- Every number must come from the sources. If you can't find it, leave it out.
- One idea per sentence. Simple words. Language: [English / Hinglish].
- End with: Comment "[WORD]" and I'll send you the link.
Then list each fact you used with the place you found it.

    Check the facts list it gives you. That's the "main approve karta hoon" part, and it's the step you should never skip.

  2. Save it as script.txt

    Put exactly the words the voice will say into script.txt. Write numbers as words (three, not 3) so the timing step can match them. Hinglish is fine: write it in English letters, the way it sounds.

Step 2 · VoiceAI voice or your own

  1. Make the voice and convert it

    Paste script.txt into ElevenLabs (or record yourself), download the MP3, put it in the folder, and convert it:

    ffmpeg -i voice.mp3 -ac 1 -ar 44100 vo.wav

    Too slow? Speed it up without changing the pitch: ffmpeg -i voice.mp3 -af atempo=1.15 -ac 1 -ar 44100 vo.wav (1.1–1.2 still sounds natural).

  2. Check the AI didn't change your words

    python3 build.py check

    It prints what it hears, 5 seconds at a time. AI voices sometimes add or skip words (one of mine added a whole sentence). If a line is different, change script.txt to what was actually said.

    The listening model is English, so Hindi words come out as English-sounding guesses. Look at the English words and the length of each line; the real test is the next step.

Step 3 · Captions + mouthbuild.py

  1. Time every word

    python3 build.py

    It lines your script up with the audio (forced alignment) and writes data.js: the start and end of every word, plus for every frame whether the mouth is open. It prints something like ok: 98 words, 41.2s.

    If it says matched 90 of 98 words, the script and the voice don't match yet. Run python3 build.py check and fix script.txt.

  2. What's inside build.py

    You don't need to change it. It's here so you can see there's no magic.

    Show build.py
    """Turns your voice into timings for the reel.
  python3 build.py check   -> prints what the recording actually says (catch a voice AI that changed your words)
  python3 build.py         -> data.js: when every word is spoken + when the mouth is open (30 fps)
Needs: script.txt (exactly what the voice says, numbers written as words) and vo.wav."""
import json, re, subprocess, sys
import numpy as np
from pocketsphinx import Decoder

FPS = 30
pcm = subprocess.run(['ffmpeg', '-v', 'error', '-i', 'vo.wav', '-ac', '1', '-ar', '16000', '-f', 's16le', '-'],
                     capture_output=True, check=True).stdout

if sys.argv[1:] == ['check']:  # free listening, 5 seconds at a time; compare with script.txt by eye
    d = Decoder(samprate=16000)
    for i in range(0, len(pcm), 160000):
        d.start_utt(); d.process_raw(pcm[i:i + 160000], full_utt=True); d.end_utt()
        print(f'{i // 32000:3d}s', ' '.join(s.word.split('(')[0] for s in d.seg() if s.word[0] not in '<['))
    sys.exit()

# 1. word timings: force-align the script to the recording
shown = open('script.txt', encoding='utf-8').read().split()           # words as they appear in captions
words = [re.sub(r"[^a-z']", '', w.lower()) for w in shown]
assert all(words), 'write numbers as words in script.txt (3 -> three)'
G2P = [('chh', 'CH'), ('aa', 'AA'), ('ai', 'EH'), ('au', 'AO'), ('ee', 'IY'), ('oo', 'UW'), ('ei', 'EY'), ('kh', 'K'),
       ('gh', 'G'), ('ch', 'CH'), ('sh', 'SH'), ('th', 'T'), ('dh', 'D'), ('bh', 'B'), ('ph', 'F'), ('jh', 'JH'),
       ('a', 'AH'), ('e', 'EY'), ('i', 'IH'), ('o', 'OW'), ('u', 'UH'), ('y', 'Y'), ('k', 'K'), ('g', 'G'), ('j', 'JH'),
       ('t', 'T'), ('d', 'D'), ('n', 'N'), ('p', 'P'), ('b', 'B'), ('m', 'M'), ('r', 'R'), ('l', 'L'), ('v', 'V'),
       ('w', 'W'), ('s', 'S'), ('h', 'HH'), ('z', 'Z'), ('f', 'F'), ('c', 'K'), ('q', 'K'), ('x', 'K S')]
def g2p(w):  # rough spelling -> sounds, for Hindi/Hinglish words and names the English dictionary doesn't know
    w, out, i = w.replace("'", ''), [], 0
    while i < len(w):
        for k, p in G2P:
            if w.startswith(k, i): out.append(p); i += len(k); break
        else: i += 1
    return ' '.join(out)
d = Decoder(samprate=16000, bestpath=False)
keys = []
for w in words:
    if d.lookup_word(w) is None:
        if d.lookup_word('x_' + w) is None: d.add_word('x_' + w, g2p(w), True)
        w = 'x_' + w
    keys.append(w)
d.set_align_text(' '.join(keys))
d.start_utt(); d.process_raw(pcm, full_utt=True); d.end_utt()
times = [(s.start_frame / 100, (s.end_frame + 1) / 100) for s in d.seg() if s.word not in ('<s>', '</s>', '<sil>', '(NULL)')]
assert len(times) == len(words), f'matched {len(times)} of {len(words)} words: run "python3 build.py check" and fix script.txt'

# 2. mouth: open on the loud peak of each syllable, closed in the dips and silences
a = np.frombuffer(pcm, np.int16).astype(np.float32) / 32768
hop = 16000 // FPS
rms = np.array([np.sqrt(np.mean(a[i:i + hop] ** 2)) for i in range(0, len(a), hop)])
rms /= np.percentile(rms[rms > .01], 90)
peak = np.array([rms[max(0, i - 3):i + 4].max() for i in range(len(rms))])
mouth = ''.join('o' if r > .12 and r / (p + 1e-6) > .6 else 'c' for r, p in zip(rms, peak))

data = {'words': [[round(s, 2), round(e, 2), w] for (s, e), w in zip(times, shown)], 'mouth': mouth,
        'duration': round(len(a) / 16000 + 1, 2)}
open('data.js', 'w').write('window.DATA=' + json.dumps(data) + ';')
print(f"ok: {len(words)} words, {data['duration']}s, mouth open {mouth.count('o') * 100 // len(mouth)}% of frames")
Step 4 · Your mascottwo pictures

  1. Make two pictures of the same character

    Use any image AI (ChatGPT, Gemini…) to make your character: chest up, facing the camera, plain or transparent background. Then ask the same chat: "Same image, change nothing except: mouth open, like talking."

    Save them as mascot-closed.png and mascot-open.png (replace the placeholder ones), same size, about 800×800.

    If the AI moves the whole picture a little, the face will jump. Fix: in any photo editor, copy just the mouth area from the open picture onto the closed one and save that as mascot-open.png. That's what I do. Background not transparent? Remove it with a free background remover first.

Step 5 · Animationreel.html

  1. Add your cards

    Open reel.html in any text editor. Every card is one line. data-at="@word" = it pops in when that word is spoken, data-out="@word" = it disappears on that word:

    <div class=card data-at="@free" style="top:200px">💸 ₹0</div>
<div class=card data-at="@link" data-out="@comment" style="top:450px;background:#ffd23f">🔗 github.com/…</div>

    Same word twice in the script? @free#2 means the second time. Change top to move a card down the screen (the video is 1080×1920). Put any HTML in a card: an <img> of a screenshot works too.

  2. Preview while you work

    Open reel.html in Chrome, press F12 for the console, and type setT(5) to see the frame at 5 seconds. That's exactly what the render will see.

  3. The full reel.html

     data-out="@word" hides it again. Same word twice? "@pipeline#2" = the 2nd time. -->

<div id=cap></div>
<img class=sam id=closed src="mascot-closed.png"><img class=sam id=open src="mascot-open.png">

<script>
const W = DATA.words, FPS = 30;
const norm = s => s.toLowerCase().replace(/[^a-z0-9]/g, '');
function cue(at) {                       // "@word" or "@word#2" -> the second when it's spoken
  const [w, n] = at.slice(1).split('#');
  const hit = W.filter(x => norm(x[2]) === norm(w))[(n || 1) - 1];
  if (!hit) throw new Error('cue word not in script.txt: ' + at);
  return hit[0];
}
const ITEMS = [...document.querySelectorAll('[data-at]')].map(e => ({
  e, at: cue(e.dataset.at), out: e.dataset.out ? cue(e.dataset.out) : 1e9, base: e.style.transform || '' }));
const CHUNKS = [];                       // captions: 3 words at a time
for (let i = 0; i < W.length; i += 3) CHUNKS.push(W.slice(i, i + 3));

function setT(t) {                       // draw the frame at time t (seconds)
  for (const it of ITEMS) {
    const p = Math.min(1, Math.max(0, (t - it.at) / .25)), back = 1 + 2.7 * Math.pow(p - 1, 3) + 1.7 * Math.pow(p - 1, 2);
    it.e.style.opacity = t >= it.out ? 0 : Math.min(1, p * 4);
    it.e.style.transform = it.base + ` scale(${t < it.at ? .5 : .5 + .5 * back})`;
  }
  const c = CHUNKS.find((c, i) => t >= c[0][0] - .05 && t < (CHUNKS[i + 1] ? CHUNKS[i + 1][0][0] : c[c.length - 1][1] + .5));
  document.getElementById('cap').innerHTML = c ? c.map(w =>
    `<span class="${t < w[0] ? 'later' : t < w[1] ? 'now' : ''}">${w[2]}</span>`).join(' ') : '';
  const open = DATA.mouth[Math.floor(t * FPS)] === 'o';
  document.getElementById('open').style.display = open ? 'block' : 'none';
  document.getElementById('closed').style.display = open ? 'none' : 'block';
}
window.setT = setT; window.DURATION = DATA.duration; setT(0);
</script></body></html>
Step 6 · Renderrender.py

  1. Make the video

    python3 render.py

    A hidden browser draws every frame (30 per second), ffmpeg glues them to vo.wav, and you get reel.mp4 (1080×1920), ready for Instagram, YouTube Shorts and TikTok. A 45-second reel is about 1,350 frames; expect a few minutes.

    Show render.py
    """python3 render.py -> reel.mp4 (1080x1920, 30 fps). A browser draws every frame of reel.html, ffmpeg glues them + vo.wav."""
import subprocess
from pathlib import Path
from playwright.sync_api import sync_playwright

FPS = 30
with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page(viewport={'width': 1080, 'height': 1920})
    errors = []; page.on('pageerror', lambda e: errors.append(str(e)))
    page.goto(Path('reel.html').resolve().as_uri()); page.wait_for_load_state('networkidle')
    assert not errors, errors
    n = int(page.evaluate('DURATION') * FPS)
    ff = subprocess.Popen(['ffmpeg', '-v', 'error', '-y', '-f', 'image2pipe', '-c:v', 'mjpeg', '-r', str(FPS), '-i', '-',
                           '-i', 'vo.wav', '-c:v', 'libx264', '-crf', '18', '-pix_fmt', 'yuv420p', '-af', 'apad', '-c:a', 'aac',
                           '-b:a', '192k', '-shortest', '-movflags', '+faststart', 'reel.mp4'], stdin=subprocess.PIPE)
    for i in range(n):
        page.evaluate(f'setT({i / FPS})')
        ff.stdin.write(page.screenshot(type='jpeg', quality=92))
        if i % 150 == 0: print(f'frame {i}/{n}')
    ff.stdin.close(); ff.wait(); browser.close()
print('done: reel.mp4')

  • A half-open mouth between closed and open, and blinks every few seconds (a third and fourth picture).
  • Many poses (pointing, thumbs up, shocked) that switch on key words, and a laptop pose with a real screenshot on the screen.
  • Sound effects (pop, whoosh, thud) generated from the same cue list, so every card makes a sound on its word.
  • Count-ups, typing terminals, crossed-out prices and a different background color per scene.
  • Rendering in 3 parts at the same time, which is how a 60-second reel renders in about 3–4 minutes.

Stuck?

"matched 90 of 98 words"

The words in script.txt and the recording are different: the AI voice added, skipped or changed something, or a number is written as a digit. Run python3 build.py check, find the line, and change script.txt to what was actually said.

Captions are a bit early or late

Usually a word the dictionary doesn't know (a brand name, Hindi words) got squeezed. Write it closer to how it sounds in script.txt (for example eleven labs instead of ElevenLabs), then run build.py again. Clear recordings with no music behind them align best.

The mouth flickers too much or barely moves

In build.py, the line that makes mouth has two numbers: .12 (how loud counts as talking) and .6 (how close to the loudest point the mouth opens). Raise .6 to .7 for less flicker, lower it to .5 for more movement.

"cue word not in script.txt: @word"

A card in reel.html waits for a word you never say. Check the spelling in data-at against script.txt. Punctuation and capitals don't matter.

Playwright: "Executable doesn't exist"

The browser isn't installed yet. Run python3 -m playwright install chromium.

pip install pocketsphinx fails

Update pip first (python3 -m pip install --upgrade pip) and try again. Still failing on Windows? Use WSL (Linux on Windows) and the Linux commands.

Can I use my own recorded voice?

Yes, it works the same. Record in a quiet room, convert it with the same ffmpeg line, and the mascot talks with your voice.

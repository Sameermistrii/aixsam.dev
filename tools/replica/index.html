Replica skill

11 free Claude skills that study an app, rebuild it, test it, read what its users hate and fix that, then help you launch your own version.

Reel keyword: CLONEClaude skillsFree · MITNo API key
Start setup ↓Official GitHub repo

What you need

  • Claude with skills (claude.ai, the desktop app or Claude Code).
  • Python 3.8 or newer for the helper tools. Nothing to pip install.

Setup, step by stepcopy each command with the button on the right

Easiestany Claude

  1. Paste this into Claude

    https://github.com/Jakeschincariol/replica-skill

install skill
Claude Code

  1. Install as a plugin

    /plugin marketplace add Jakeschincariol/replica-skill
/plugin install replica-skill@replica-skill

    As a plugin the commands are named /replica-skill:replica-recon and so on. Want the short /replica-recon? Copy the folders instead:

    git clone https://github.com/Jakeschincariol/replica-skill.git
cp -r replica-skill/replica-* ~/.claude/skills/
Everyoneuse it

  1. Start with recon

    Give it the app you want to study:

    /replica-recon https://the-app-you-want-to-study.com

    It maps the screens, flows and data into a replica/ folder in your project.

  2. Run the rest in order

    Each skill reads what the previous one wrote:

    recon → architect → design → build → backend → test → diff → entrepreneur → brand → launch → deploy

Try this first

/replica-entrepreneur on an app you're only thinking of cloning: it reads real reviews and tells you what users hate
/replica-diff to score your clone against the original

Heads up: It rebuilds what an app does (features and flows), never what it owns: not its code, logo, copy or content. The skills enforce this, and /replica-brand gives your version its own name and look.

What is Replica skill?

Replica is a set of eleven free Claude skills by Jake Schincariol that help you clone an app: study it, rebuild it, test it and launch your own version. It's MIT licensed, needs no signup and no API key, and connects to nothing.

What makes it different is the order. One skill maps the app you want to study, the next ones plan, design, build and test your version, and one of them, the Entrepreneur, reads what the original app's users complain about so your version fixes it. Every skill writes into a replica/ folder that the next one reads.

It copies what an app does, its features and flows, never what it owns: no code, logo, copy or content. The brand and sweep tools check for that before you launch.

What Replica skill can do

  • /replica-recon maps an app's screens, flows, components and data model from public pages, screenshots, store listings and your own account.
  • /replica-architect plans the stack, database schema and API.
  • /replica-design rebuilds the design system as tokens: colours, type, spacing, components, with your own assets.
  • /replica-build and /replica-backend build the app screen by screen, then add sign-in, database, payments and integrations.
  • /replica-test and /replica-diff click through every flow looking for bugs, then score your clone against the original and list what's missing.
  • /replica-entrepreneur reads real reviews (every quote it shows links to its source) and turns the top complaints into fixes and a positioning angle.
  • /replica-brand, /replica-launch, /replica-deploy give it a new name and look, write the landing page and store listing, and put it live on your domain.

What you need

  • Claude with skills (claude.ai, the desktop app or Claude Code).
  • Python 3.8 or newer for the helper tools. Nothing to pip install.

Questions people ask

Is Replica skill free?

Yes. It's open source under the MIT licence, with no signup and no API key. You only need Claude.

Is it legal to clone an app with it?

Replica is built to copy features and flows, clean-room style, not code, logos, text or content, and its brand and sweep tools check that nothing of the original is left. Laws differ by country, so check with a lawyer before you sell a clone of a well-known product.

Do I need Claude Code?

No. Claude Code gets all eleven skills plus the Python helper tools. In any other Claude chat you can paste a single SKILL.md at the top and it works as a mode, just without the tools.

Can I run only one of the skills?

Yes. Each skill works on its own. Running /replica-entrepreneur on an app you're only thinking about cloning is a quick way to find out if it's worth it.

What do the Python tools need?

Python 3.8 or newer. They use only the standard library, so there's nothing to pip install, and none of them touch the network.

Graphify

Turns your whole codebase into a knowledge graph, so Claude Code, Cursor or Codex ask the graph instead of re-reading every file.

What is Graphify?

Graphify is a free, open-source tool that reads a folder (your code, notes, PDFs, screenshots, diagrams) and builds a knowledge graph of how everything connects. Your AI coding assistant can then ask the graph instead of opening and re-reading every file in each new session.

Code is parsed locally with tree-sitter, so it never needs an AI to understand your functions and imports. Docs, papers and images are read by Claude to pull out concepts and links. Every connection in the graph is marked as extracted, inferred or ambiguous, so you can see what was found and what was guessed.

How much it saves depends on size. On the project's own benchmark of 52 files (3 repos, 5 papers, 4 images) a query used 71.5× fewer tokens than reading the raw files; on 4 files it was 5.4×, and on 6 small files about the same as reading them. The bigger the folder, the bigger the win.

What Graphify can do

  • An interactive map graph.html: click, search and filter your code by community.
  • A one-page report GRAPH_REPORT.md lists the "god nodes" everything runs through, surprising connections, and questions the graph can answer.
  • Questions in plain English /graphify query, path and explain answer from the graph.
  • Stays up to date --update re-reads only changed files; --watch or a git commit hook rebuilds it automatically.
  • Exports an Obsidian vault, a wiki for agents, SVG, GraphML (Gephi, yEd), Neo4j, or an MCP server.
  • Any mix of files Python, TypeScript, Go, Rust, Java, C/C++ and more, plus Markdown, PDFs and images.

What you need

  • Python 3.10 or newer.
  • uv (installs Graphify in its own clean space). Step 1 shows how.
  • An AI coding assistant: Claude Code, Cursor, Codex and 20+ others.

Setup, step by stepcopy each command with the button on the right

  1. Install uv

    Mac:

    brew install python@3.12 uv

    Windows (PowerShell):

    winget install astral-sh.uv

    Linux:

    curl -LsSf https://astral.sh/uv/install.sh | sh

  2. Install Graphify

    uv tool install graphifyy

    Two y's: graphifyy is the official package. Other "graphify" packages aren't theirs. The command you type is still graphify.

  3. Connect it to your assistant

    graphify install

    It detects Claude Code automatically. For others: graphify cursor install, or graphify install --platform codex.

  4. Build the graph

    Open your assistant in your project folder and type:

    /graphify .

    You get a graphify-out/ folder with GRAPH_REPORT.md (the big picture), graph.json and an interactive graph.

  5. Make it always use the graph

    Run this once in the project:

    graphify claude install

    Now Claude checks the graph before searching your files.

Try this first

/graphify query "what connects auth to the database?"
/graphify path "UserService" "DatabasePool"
/graphify explain "RateLimiter"
/graphify . --update (after you change code)

Stuck?

"graphify: command not found"

Run this, then close and reopen your terminal:

uv tool update-shell
Does my code leave my computer?

No. Code is parsed locally. Only docs/media go through an AI backend, and only if you set one up.

How do I remove it?
graphify uninstall

Questions people ask

Is Graphify free?

Yes, it's free and open source. Building the graph from code costs nothing; reading docs, PDFs and images goes through your AI assistant, like any other request.

Why is the package called graphifyy?

The PyPI name graphify is being reclaimed, so the official package is temporarily graphifyy (two y's). The command you type is still graphify.

Does it work with Cursor or Codex, not just Claude Code?

Yes. graphify install sets up Claude Code, and there are install options for Cursor, Codex and other assistants (step 3 above).

“graphify” is not recognized on Windows

Add Python's Scripts folder to your PATH (%APPDATA%\Python\Python3xx\Scripts), or install with uv or pipx, which handle the PATH for you.

Will it really save 71.5× tokens on my project?

Only on a big, mixed folder like the benchmark's 52 files. Small projects that already fit in the context window save little; there the value is seeing the structure, not saving tokens.

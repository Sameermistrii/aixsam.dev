Prefer doing it by hand?

Install once, then run these in the kit folder (on Windows type python instead of python3). The full manual is the free guide: aixsam.dev/tools/pipeline.

pip install pocketsphinx numpy playwright
python3 -m playwright install chromium
ffmpeg -i voice.mp3 -ac 1 -ar 44100 vo.wav
python3 build.py check
python3 build.py
python3 render.py shots 2,5,9
python3 render.py
python3 render.py cover
